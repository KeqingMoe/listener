# Bot 运行诊断面板

查看唤醒、模型请求、工具执行和接入事件。业务接口只读本地数据，不连接 OneBot、不调用模型、不重放工具；只有登录和退出会改动面板自己的会话状态。

## 启动和登录

```sh
npm run dashboard:build
npm run dashboard:start
# http://127.0.0.1:3210/
```

服务读取仓库的 `config.toml` 与 `.env`，默认监听 `127.0.0.1:3210`，可用 `--host`、`--port` 或环境变量 `DASHBOARD_HOST`、`DASHBOARD_PORT` 修改。

在 `.env` 中设置 `DASHBOARD_PASSWORD`（12 字符以上，不要复用其他密钥），修改后重启服务。未配置时页面和接口都拒绝访问。更换密码会撤销已有会话。会话 Cookie 为 HttpOnly、SameSite=Strict，最长 7 天。

面板包含群消息、模型上下文和工具内容，只应对授权人员开放：通过 Tailscale、SSH 转发或 HTTPS 入口访问，不要把 HTTP 登录直接暴露到公网。HTTPS 部署设置 `DASHBOARD_COOKIE_SECURE=1`。

## 安装为应用

通过 HTTPS 打开面板，在 Chrome 菜单中选择“添加到主屏幕 / 安装应用”。清单使用固定的应用标识和根路径启动地址，独立窗口中可访问所有面板页面；安装不会绕过登录与接口鉴权。

图标使用 Bot 头像的本地快照，标准与安卓自适应图标都满幅使用头像，不额外加边，由系统按启动器形状裁切。不请求 QQ 外链，也不随账号头像自动更新；已有安装项可能缓存旧图标，未更新时可移除后重新安装。清单与图标无需登录即可获取，不包含账号、群号或凭据。不注册 Service Worker，不提供离线功能，不增加业务数据的持久缓存。

允许系统启动器发起的跨站顶层 GET/HEAD 导航取得公开页面，以及跨站读取公开安装清单和图标；跨站 API（含登录/退出）仍拒绝，公开页面也不允许跨站 iframe 或普通 fetch，Host 校验与接口鉴权不变。

若安卓仍提示“无法安装”但允许添加快捷方式，还需检查 Chrome 版本、GMS 和相关安装服务的网络连通性；桌面可安装或移动端模拟检查通过，不等于已验证真实安卓安装。

## 视图

- **总览**：请求结果、token、缓存命中率、TTFT/TPS、模型与工具耗时，以及按群组、按模型的汇总。早期没有记录模型名的请求归入“未记录模型”。
- **唤醒**：列表显示每次唤醒的 Bot 发言摘要。详情的“执行过程”按时间展开：发言显示为气泡，读取到的消息显示为“发言人：内容”，JavaScript 任务显示说明、代码和执行结果（返回值按原文显示，整体是 JSON 对象或数组时才按 JSON 高亮，长内容默认折叠），其余工具显示参数概要和失败原因；原始参数与结果在每步的“原始数据”里。at 与发言人优先显示本次读到的名字，否则用本群消息记录中最近的群名片或昵称。
- **模型请求**：包括进行中、成功、失败、超时、取消和中断的请求，可查看请求/响应快照、推理、错误和工具调用，可按配置中的模型名（`[models.<名字>]`）筛选。
- **工具**：并排展示直接调用账本与 JavaScript 宿主内部调用观测，按普通工具、流程控制、JS 调度分栏；保留两条来源的结果与耗时，不混成业务操作总数。
- **事件**：接收、触发/跳过、连接、发送等运行事件，包括没有产生唤醒的情况。

工具明细区分“请求发送的内容 / 请求操作 / 调用参数”和工具返回的结果证据；看到发送气泡不代表已发送成功。仅提交、待确认、暂存、后台句柄与重复结果不当作新执行成功；未知不等于失败，错误或取消也不代表副作用已撤销。“工具返回成功”仅描述顶层返回，不保证对方已读或沙箱内部所有调用成功，原始数据仍可展开核对。

`execute_javascript` 的 `sync/auto` 显示前台等待时限（含沙箱排队与启动），进行中按调用开始时间估算“约 N 秒后超时终止 / 转后台”。倒计时用已有响应时间校准并在本地更新，不增加轮询，也不改变工具执行；到零先等待服务端状态确认。未开始、缺少时限或开始时间时不猜测；已结束或已返回后台句柄的调用不再倒计时。

沙箱内部调用的非成功记录单独显示序号、工具名、状态和原因，区分错误、结果未知、待确认，不因外层脚本返回成功而隐藏。默认展示前 5 条，可展开已有明细；服务端未返回的条数、明细缺失或格式异常会明确提示，不把缺记录当作没有异常，也不会为展开额外请求数据。

明确返回 `pending` 后台句柄的执行调用、查询/取消记录中的 JavaScript 任务 ID 旁可按需展开“关联记录”，串联同群的执行、查询、取消、结果收件及写入模型上下文记录，并跳转至有证据对应的模型请求或唤醒；通知唤醒也有反向入口。同步或 auto 前台已完成即使有任务 ID，也不默认显示后台关联入口；仅请求 async 模式不当作已经转后台。只读取宿主协议字段，不把代码、返回文本或普通用户消息中提及的 ID 当作关联证据。查询失败仍可作为查询意图显示，不据此确认任务存在；通知进入模型上下文不代表模型已读取，更不代表已发群消息。

从工具调用展开时，以账本 ordinal 先精确核对同群当前调用及任务 ID，并标记“当前调用（直接核对）”；此锚点不受时间筛选限制，旧记录没有时间就不补猜时间。其他关联按页面时间范围检索（最多 31 天），不是实时任务状态查询。仅展开时加载，沿用已有刷新机制，收起不轮询；“重新检索此范围”不改变时间筛选。每类优先检查最近 2000 条相关日志、最近 500 条通知收件记录；已匹配通知另按 ID 核对，最多返回 200 条关联，优先保留当前调用锚点，其余取最近记录。唤醒跳转仅按已匹配的 wake ID 使用索引有界核对，不再因全群累计唤醒多而报不完整。

界面分别说明候选数量上限、读取预算、过大/无法解读的候选、已匹配记录缺失、索引不可用等原因；全群收件历史覆盖限制不等于这个任务丢了记录。通知收件阶段没有专属模型请求，投影到上下文后才有对应的唤醒证据。未找到不表示未发生；不会打开沙箱运行库、迁移数据库或执行 Bot 动作。

`web_search` 的已有返回直接展示标题、来源 URL、摘要和来源标注时间，分别提示部分查询失败、未返回来源以及服务端省略来源；失败或缺失记录不当作“没有搜索结果”。`web_fetch` 展示请求/返回来源、HTTP 状态、正文纯文本预览与分页信息，区分重定向目标尚未读取、分页切片为空和确认的整页正文为空。摘要与正文可展开已有文本；来源最多展示 10 条、正文最多展示 20000 码点，本页展示截短与服务端截断分别提示，原始数据仍可核对。

网页链接仅手动点击时另开页面，不发送来源页面地址；非 HTTP(S)、含身份凭证、明显本机/私网字面量等异常链接只显示文本。此检查不解析 DNS，也不保证目标可信或可访问。正文与摘要不执行 HTML/Markdown，不加载远程图片；展开、刷新记录均不重新搜索、抓取或自动续读网页。

`create_artifact`、`create_image` 和 `list_artifacts` 用产物卡片展示已有名称、用途、媒体类型、字节大小、图片尺寸、哈希及记录的创建/到期时间，创建请求与返回信息分开，不用请求参数补成已生成的产物。到期时间只是历史记录，不据此断言文件现在仍可用或已删除。列表默认显示 10 条，可每次再显示 10 条已有记录；最多保留 100 条，引用 ID 数组最多展示 20 条，硬上限与字段截短都有提示。展开不请求新数据，原始返回仍可核对。

`upload_group_file`、`send_group_image` 和 `view_images` 单独列出请求引用 ID 与返回证据，不从代码、文件内容或其他记录猜关联。生成不代表上传/发送；上传只在已结束且明确 `uploaded=true`、`effect_confirmed=true` 等证据一致时提示工具回报成功，未拿到新文件 ID 不当作上传失败。发图执行与本地同步失败分开，图片加载也不等于已发图或模型已读。产物 ID 可复制，但不生成下载链接，不读取文件、像素或加载图片。

群管理写操作按“请求目标与参数 / 返回阶段 / 已有原因”展示，包括禁言、解禁、撤回、名片、群名、头衔、全员禁言、踢人、管理员、精华、公告、退出群、群文件目录/文件删除与入群申请处理等。成员名称只使用同一记录范围内已有的名字；消息、公告、资源句柄不猜目标内容，返回对象中的 ID 不回填为请求目标。关闭、拒绝等 `false` 值和移除头衔的空字符串明确展示，公告与理由只按纯文本本地展开，截短会标注，原始数据仍可核对。

待确认不等于已执行，提交不等于生效或已入群；普通 `ok`、API 自报成功也不自动当作目标删除已核实。账本未知、异常或矛盾字段会保守提示，重复/缓存结果不算新的执行；派发后取消不会抹掉已有回执，也不证明已撤销。确认提示消息 ID 与操作目标分开，原因保留原码及已有解释。不提供执行、确认、重试或反向操作按钮，`refresh_list` 仅显示返回建议，不读取远端列表或目标当前状态。

筛选和选中记录保存在 URL 中。总览切走后仅在内存保留一份页面、图表和同步游标，暂停请求；同筛选切回先显示缓存，再增量同步。筛选改变则重新加载，退出登录或刷新整个网页会清空缓存。内容支持搜索和复制，复制的始终是完整原文。正文不执行 HTML，也不加载远程图片；图片只显示 `image_id`。

凭证（API 密钥、Authorization、Cookie、密码、确认码）在展示前清除，大段 base64 图片只保留省略标记。思考内容只来自服务商返回的可读文本或摘要；只有加密内容时显示占位。

## 计量口径

- **散点显示范围**：纵轴下界随数据自动调整，不固定从 0 开始；95%/99% 分别从两端各裁去 2.5%/0.5%（数量向下取整，边界同值保留，少于 20 个有效点不裁剪）。仅影响散点显示，汇总、柱状图及中位数/P5/P95 趋势统计仍用全量数据。中位数为实线，P5/P95 为淡虚线，标出滑动窗口中间约 90% 的分位范围，不是回归置信带，不填色。“辅助线”可选分位线、拟合线或隐藏（默认分位线），选择保存在 URL，切换不请求数据。
- **拟合线**：仅总输入、缓存输入支持；按群各画一条并列出颜色图例，选择全部群时不会混群拟合。每段至少 5 个有效样本，以最多 9 个相邻请求做 Theil–Sen 稳健局部直线拟合，再轻度平滑连接；不强制单调，统计包含被裁剪的点，原始散点保持不变。总输入下降同时达到 10% 和 2048 tokens 时断段，间隔同时达到 30 分钟和该群中位间隔的 5 倍时也断段，缺失值处不连线。这些是启发式边界，不代表已确认压缩。缓存孤立低命中不单独断段；拟合表达主要趋势，不代表逐次真实命中量。切到不支持的指标时暂时隐藏，保留拟合选择，切回总输入/缓存输入后恢复。

- **输入/缓存/输出**：输入指未缓存部分（总输入减缓存命中），输出沿用服务商计量，推理 token 不重复相加。缺失值显示 `—`，不当作 0。
- **缓存命中率**：缓存量之和除以同一批样本的总输入之和，只用两者都有记录的请求。
- **TTFT**：从发出请求到首个有效输出的等待时间，汇总取平均。
- **TPS**：输出 token 之和除以首个输出到协议完成的时长之和，不含 TTFT。这是客户端观测值，输出很短的请求单条数值可能偏高。
- **模型墙钟**是请求时间区间的并集；**非模型耗时**是唤醒墙钟减去模型墙钟，包含工具、调度和数据库访问等。工具累计耗时与墙钟可能重叠，不能直接相加。
- 请求成功不等于已回复，工具完成不等于 QQ 上的最终效果。

## 工具统计的真相源

- **直接来源**：各群 `model_tool_ledger`，仍按 `proposed_at` 选择记录。`GET /api/tools` 原有 `items[].calls` 及结果、耗时字段始终仅指直接账本，包含尚未执行、拒绝、跳过等提案；本次不改变 `ModelSession.summarizeTools` 的既有语义，也不往旧数组塞入内部独有工具的伪零行。
- **内部来源**：Bot 在 `SandboxService.callTool` 的宿主入口及返回边界，向现有遥测库的 `tool_call_observations` 写入开始/结束观测。以 `(self_id, group_id, job_id, seq)` 标识一次调用，重复观测幂等；真正再次调用使用新序号，即便返回缓存/重复结果也算一次新的请求，不代表一次新的外部副作用。按该调用的 `started_at` 筛选，而不是脚本发起、查询或通知时间。两条来源都展示当前保留的结果观测，不是截止 `until` 当时的状态快照；迟到回执可以更新固定历史窗口。
- **不重构历史**：不从代码文本推测执行；不累计 `execute_javascript` 返回、`query_javascript_jobs` 或通知中的摘要。开始/结束更新只算一条调用，后台任务迟到的回执仍更新原事实。宿主入口之前被沙箱拒绝、或根本没有运行的代码表达式，不属于这里的宿主调用观测。
- **结果与生命周期正交**：没有结束观测可能是仍未返回、丢记录或进程消失，不显示为确定的“运行中”或“失败”。写端关闭只标记自己的未结束观测中断，不为它们伪造 `finished_at`，也不恢复/中断其他活写端；写端仍可用时的迟到结束保留已有中断证据。缺开始观测、时钟反转的记录不参与耗时分位数。宿主拟返回给脚本的有界标识型 `status` 在旧摘要归一化之前保留，不证明代码已收到或消费；`partial`、`pending`、缺失/无效状态不会当作 `ok`，任何状态都不单独证明外部效果已确认。
- **来源与角色是两个维度**：普通工具包括读取、发言、管理等；流程控制为 `finish`、`ack_events`；JS 调度为 `execute_javascript`、`query_javascript_jobs`、`cancel_javascript_job`。角色不评价是否有用。默认展示普通工具，可切换其他角色并按任一来源排序；两层不相加成独立业务动作数，也不当作模型请求数、唤醒数或工具暴露率。
- **覆盖未知不补零**：新增可选 `internal` 响应给出已保留观测数及启用时间、裁剪边界、采集器历史故障提示，不承诺完整总量。旧响应、旧数据库、未启动新采集、早于启用的窗口或不兼容 schema/index 显示未知。横跨启用/裁剪时间的窗口保留已观测事实并告警；历史故障提示不意味着本次筛选的每个群都有丢失。没有某来源的记录显示 `—`，不能推断从未调用。
- **只读与预算**：面板只读现有遥测和授权群会话库，不打开 `sandbox.sqlite`，不在读取时建表或迁移。内部按授权群/时间的固定索引查询，跨群最多读 10000 条；超过上限该来源返回不可用并提示缩小范围，不发布部分合计。直接来源仍沿用原 10000 条限制。内部写入、结束回执和覆盖元数据变化都经现有 resource-sync 失效；动态撤权仍重新校验。
- **部署边界**：只更新 Dashboard 不会让旧 Bot 自动开始采集。需运行包含新采集器的 Bot 后才产生新事实，过去的内部调用仍未知。本步骤不改变工具权限、调度、执行、模型返回协议或工具暴露方式。观测不保存参数、代码、结果正文或任意异常文本；采集失败不替换工具结果，恢复后保存已知丢弃计数，无法持久化且同时退出的故障仍可能留下未知缺口。

## 数据与保留

运行指标、请求快照、运行事件及内部工具调用观测在 `storage.telemetry_path`；会话、直接工具账本和群消息记录来自各群的数据库，面板只读打开。内部调用观测独立保留 7 天、最多 50000 条，容量裁剪可能一起移除边界同时间戳记录；裁剪边界原子写入元数据，已删除的旧调用不因迟到回执复活。生产者元数据保留有调用引用的记录及最多 5000 条无引用记录，历史丢弃/冲突计数不会随元数据清理消失。逻辑保留上限不等于 SQLite 文件物理大小上限。

请求快照保留 7 天、上限 256MiB，超出时从最旧的开始清理；Responses 响应里回显的系统指令和工具定义不重复保存。运行事件保留 7 天、约 30000 条。查询范围最长 31 天，列表分页，正文只在打开详情时加载并有总量上限。

## 文件权限

systemd 服务需要读取 Bot 数据，只允许写入 `storage.directory/dashboard-auth/`（权限 0700，属主为服务用户）。`ReadWritePaths` 只放这个子目录，其余数据保持只读。
